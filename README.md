# Programming Fundamentals Project: Inventory Tracker

**New here?** Start with `PROJECT_OVERVIEW.md` for what you're building and
why, then `GETTING_STARTED.md` for turning this template into your own repo
step by step.

**Due:** 1.5 weeks. See `TIMELINE.md` for a suggested day-by-day pace.

## Setup

Already included in this template — nothing to build yourself this time
(unlike Module 0): `.gitignore`, `LICENSE`, and this repo's own git history.
`git-version-control` isn't being tested again this module, so re-building
those from scratch would just be friction. You will still need:

- **Python 3** — check you have it: open Terminal and run `python3
  --version`. If it's missing, install from https://python.org (the macOS
  installer) or via Homebrew (`brew install python3`).
- **VS Code** — already introduced in Module 0.
- **[Python Tutor](https://pythontutor.com/)** — free, browser-based. Not
  required to complete the project, but genuinely useful for stepping
  through your own loop/function code line by line if you get stuck on why
  a variable has the value it does.

See `GETTING_STARTED.md` for turning this template into your own repo.

## The data

Everyone in this cohort tests against the same file — already included at
`data/inventory_transactions.txt`, no download needed. See `data/SOURCE.md`
for where the item names came from and, importantly, the deliberate edge
cases built into this exact file that your script needs to survive.

## What to do

See `starter/inventory.py` — the class/function structure and docstrings
are given, the logic isn't; every `# TODO:` is yours to fill in. `starter/
REFLECTION.md` is the required written piece once your script runs.
`TIMELINE.md` has a suggested pace. Your instructor shares the full
step-by-step checklist and grading rubric separately through the
classroom — not this repo.
